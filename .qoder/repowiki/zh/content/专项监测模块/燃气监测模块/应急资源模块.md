## 模块概述

应急资源模块是燃气模块右侧功能区的重要组成部分，负责展示和管理应急响应所需的各类资源。该模块严格遵循GAS_MODULE_README.md的设计规范，采用卡片式布局展示应急人员、车辆、装备和物资的数量与状态信息，为应急响应提供直观的数据支撑。

### 核心功能特性

- **资源统计展示**：通过统计卡片展示应急专家、医疗队伍、避难场所、救援队伍、救援人员、救援仓库等六类资源
- **车辆统计**：专门的救援车辆统计功能
- **中心圆环设计**：独特的应急资源圆环视觉元素
- **响应式布局**：基于网格系统实现灵活的布局适配
- **数据接口对接**：与后端API无缝集成

## 实时更新机制

应急资源模块具备实现数据实时更新的能力，为应急响应提供及时的信息支撑。

### 实时更新架构

```mermaid
sequenceDiagram
participant Component as EmergencyResourceModule
participant Store as 状态管理
participant WebSocket as WebSocket连接
participant API as 资源API
participant Timer as 定时器

WebSocket-->>Store : 连接确认
loop 实时更新循环
WebSocket-->>Store : 资源变更通知
Store->>Component : 状态更新

Note over Timer : 定期轮询(如每5分钟)
Timer->>API : 获取最新数据
API-->>Store : 同步数据

end
```

### 实时更新实现方法

#### 1. WebSocket连接管理

- **连接建立**：模块启动时建立WebSocket连接
- **心跳检测**：定期发送心跳包维持连接
- **断线重连**：网络异常时自动重连机制

#### 2. 数据同步策略

- **增量更新**：只更新发生变化的资源项
- **全量同步**：定期进行全量数据同步
- **冲突解决**：处理并发更新导致的数据冲突

#### 3. 性能优化措施

- **防抖处理**：避免频繁的DOM更新
- **内存管理**：及时清理过期的资源数据
- **缓存策略**：合理使用浏览器缓存

## 故障排查指南

应急资源模块可能出现的常见问题及解决方案：

### 资源数据不一致问题

#### 问题表现
- 资源统计数字显示异常
- 车辆统计数量不正确
- 资源卡片显示空白

#### 排查步骤

```mermaid
flowchart TD
A[发现问题] --> B{检查网络连接}
```

#### 解决方案

1. **网络连接检查**
   - 确认网络连接稳定
   - 检查防火墙设置
   - 验证API域名解析

2. **API响应验证**
   ```javascript
   // 检查API响应格式
   const response = await getEmergencyCapacityList();
   console.log('API响应:', response);
   
   // 验证数据完整性
   if (!response || !Array.isArray(response)) {
       console.error('API返回数据格式错误');
   }
   ```

3. **数据映射调试**
   - 检查typeMap映射表
   - 验证资源名称匹配
   - 确认count字段存在

### 调度功能失效问题

#### 问题表现
- 资源分配无法执行
- 状态更新不生效
- 调度记录丢失


#### 常见原因及解决

   - 验证API访问权限
   - 确认调度操作权限

2. **接口异常**
   - 检查调度API状态
   - 验证请求参数格式
   - 确认响应数据结构

3. **数据一致性**
   - 检查资源状态同步
   - 验证库存数据准确性
   - 确认分配记录完整性
