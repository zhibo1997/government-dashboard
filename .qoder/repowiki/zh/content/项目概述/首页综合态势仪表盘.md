## 核心组件分析

首页综合态势仪表盘采用Vue 3 + Pinia + TypeScript技术栈，基于VueCesium实现三维地理信息可视化。系统通过嵌套路由和持久化布局确保地图和头部导航在模块切换时不重新渲染，提升性能和用户体验。

系统入口文件`main.ts`初始化Vue应用，配置Pinia状态管理、Naive UI组件库和VueCesium三维地图框架。`App.vue`作为根组件，通过`n-config-provider`设置中文语言环境，并定义全局样式布局。

## 数据流与服务调用

系统通过`statusService.ts`提供综合态势数据接口，包括风险等级、隐患等级、监测报警、预警处置和基础设施总览等统计信息。数据获取采用分层架构，通过`dictionaryService.ts`统一管理字典数据缓存。

```mermaid
sequenceDiagram

participant StatusService as 状态服务
participant DictionaryService as 字典服务
participant HttpClient as HTTP客户端
HomeModule->>StatusService : getBasicFacilitiesOverview()
StatusService->>HttpClient : GET /gspspDtransPubbasicfacilitiesinfo/list
HttpClient-->>StatusService : 基础设施数据
StatusService-->>HomeModule : 处理后的总览数据
HomeModule->>DictionaryService : getCachedDictionaries()
DictionaryService->>PiniaStore : 获取缓存字典
alt 缓存存在
PiniaStore-->>DictionaryService : 返回缓存数据
else 缓存不存在
DictionaryService->>API : 请求字典数据
API-->>DictionaryService : 字典数据
DictionaryService->>PiniaStore : 缓存数据

end

StatusService->>HttpClient : GET /zzts/fxdj/count
HttpClient-->>StatusService : 风险等级数据
StatusService-->>HomeModule : 风险统计
```

## 持久化布局机制

系统通过`PersistentLayout.vue`实现持久化布局，采用嵌套路由设计模式。地图组件和头部导航作为持久化层，不随路由切换而重新渲染，子路由内容通过`<router-view>`动态加载。
