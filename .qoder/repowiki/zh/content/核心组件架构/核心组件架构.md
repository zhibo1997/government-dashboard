## 项目概述

该政府dashboard项目是一个基于Vue 3和Cesium的地理信息系统，采用现代化的前端架构设计，实现了完整的GIS功能和响应式布局。项目核心围绕地图可视化、数据展示和用户交互展开，具有清晰的组件层次结构和完善的通信机制。

#### 响应式计算逻辑

1. **缩放模式支持**
   - `width`模式：按宽度比例缩放
   - `height`模式：按高度比例缩放
   - URL参数优先级控制
   - 默认宽度模式

2. **尺寸计算算法**
   ```typescript
   // 宽度模式计算
   scale = windowWidth / baseWidth
   
   // 高度模式计算  
   scale = windowHeight / baseHeight
   
   // 范围限制
   scale = clamp(scale, minScale, maxScale)
   ```

3. **事件监听机制**
   - 窗口resize事件防抖处理
   - URL参数变化监听
   - DOM变化观察器
   - 响应式数据更新
