# 后台服务 API 文档

> 生成时间：2026-06-16

## 基础配置

| 配置项 | 值 |
|--------|-----|
| API 基础地址 | `/clapi` |
| 默认参数 | `Dsbm: '420200', Qhbm: '420222'` |
| 认证方式 | `Authorization: {token}` |
| 超时时间 | 10s (dev) / 15s (prod) |

## 模块编码

| 模块 | Sszx 编码 |
|------|-----------|
| 供水 | `csaqzx_gs` |
| 排水 | `csaqzx_ps` |
| 燃气 | `csaqzx_rq` |
| 桥梁 | `csaqzx_ql` |
